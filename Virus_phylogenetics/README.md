Virus characterization and phylogenetic analysis
==============================

We identified genes with Gene Ontology (GO) terms corresponding to viral-related processes. The genes were manually annotated by aligning them against the NCBI non-redundant protein sequence database using blastx. We found eight sequences from picornavirales and Narnavirus that were homologous to the viral genes we identified. We further extracted potential open reading frames (ORF) and conserved domains by using those genes as queries on NCBI’s ORF Finder and Conserved Domain Database (CDD), respectively. 

To determine whether broodcare workers host the same viruses as bodyguards, we compared viral transcript abundances between workers from the same colony engaged in different tasks. First, we followed Viljakainen et al.. (2023) to obtain reads per kilobase of transcript per million mapped reads (RPKM) values from the previously calculated transcript-level counts for each sample using the edgeR package (Chen et al., 2025) in R version 4.2.1 (R Core Team, 2020). Then, we obtained TPM from RPKM by dividing each RPKM by the sum of RPKMs for the sample and multiplying by 10^6. 

To assess whether these viruses were potentially replicating within an ant host, we followed the criteria suggested by Xavier et al. (2021) and Pettersson et al. (2019). We calculated viral sequence abundances across ant workers using the bbsplit.sh perl script implemented as part of BBMap v36.x (Bushnell, 2014). We then compared the abundances of viral reads to the abundances of reads of three housekeeping genes: cytochrome c oxidase subunit I (COX1), eukaryotic translation elongation factor 1 epsilon-1 (eEF1E1-epsilon), and ribosomal protein L18 (RPL18). We also determined whether each virus in each sample had an abundance higher than 0.01% unambiguous mapped reads -the reference value suggested in Xavier et al. (2021). For phylogenetic reconstruction, we used the full-length amino acid sequences of the non-structural RNA-dependent RNA polymerase (RdRp), a highly conserved gene suitable for viral phylogenetic reconstruction (Venkataraman et al., 2018) (Table S6 and Table S7). We extracted RdRp sequences from genes identified as viral from CDD. Unclassified and classified representative amino acid sequences of species of each family were used in the phylogeny as suggested by Xavier et al. (2021). We also included viral sequences with the most similar matches based on the BLASTx search. We used one sequence of an Ourmiavirus and three species in the family Secoviridae as outgroups for the phylogenetic placement of Narna-like viruses and Picorna-like viruses, respectively. We aligned viral protein sequences using L-INS-i MAFFT v7.505 with a gap penalty of 1.53 (Katoh et al., 2005), which generated a 725-site alignment. We generated a maximum-likelihood phylogenetic tree based on amino acid sequences using the software program IQ-Tree v1.6.12 (Nguyen et al., 2015) with ultrafast bootstrap (UFBoot) (Hoang et al., 2017). We also implemented the amino acid substitution model Blosum62+FO with optimized base frequencies by maximum-likelihood. (Henikoff and Henikoff, 1992). We evaluated the support for each node with 1000 bootstrap replicates. Phylogenetic trees were visualized and rooted in FigTree (Rambaut, A., 2018). Finally, we performed a pairwise comparison of amino acid (AA) similarity across the samples included in the phylogenetic analyses. We obtained the number of AA substitutions using a Poisson correction model and a Gamma distribution in MEGA11 (Tamura et al., 2021).
